# Blue Team Investigations Portfolio

Hands-on SOC and DFIR case studies focused on **incident investigation, threat detection, and response workflows** across cloud and endpoint environments.

## Case Studies

### Cloud Incident Response — AWS & GCP

Investigation of cloud security incidents using logs and telemetry from AWS and GCP, covering detection, evidence analysis, attack-path reconstruction, and remediation.

### Phishing Incident Response

End-to-end investigation of a suspected phishing incident, including email analysis, indicator extraction, threat assessment, containment, and recommended remediation.

## Skills Demonstrated

* SOC alert triage and incident investigation
* Cloud and endpoint log analysis
* Digital forensics and evidence analysis
* MITRE ATT&CK technique mapping
* Attack timeline reconstruction
* Root cause analysis
* Containment and remediation planning
* Incident documentation and reporting

## Purpose

This repository demonstrates practical blue-team investigation workflows, with an emphasis on **turning security telemetry into actionable findings and response decisions**.
